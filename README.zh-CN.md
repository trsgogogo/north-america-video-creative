# 北美短视频创意与拆解

把参考视频拆成可理解的创作结构，再为你的产品写出原创英文钩子、脚本和分镜。

## 核心流程

参考视频 → 结构拆解 → 匹配产品和受众 → 原创钩子 → 脚本与分镜 → 创意变体 → 根据真实数据迭代。

- 36 类钩子：按场景选择，支持一次输出全部类型。
- 4 类脚本：故事、共鸣搞笑、知识教学、过程展示。
- 时间轴拆解：第一帧、第一句话、信息推进、产品露出、证据、节奏和 CTA。
- 制作交接：英文口播、时间段、画面、屏幕文字、所需素材。
- 数据反馈：区分观察与推测，不把高播放量当成因果证明。

这是短视频创作 workflow，不是完整 GTM，也不直接渲染成片或保证爆款。

## 安装与使用

Codex 默认安装位置：

```sh
git clone https://github.com/trsgogogo/north-america-video-creative.git ~/.codex/skills/north-america-video-creative
```

如果自定义了 CODEX_HOME，请使用对应的 skills 目录。未出现时可在新会话中查看。

示例：

> 用 $north-america-video-creative 拆解这个视频，提炼结构，再为我的产品写一个面向美国观众的 30 秒版本。

> 这个选题给我 10 个英文钩子，选出最好的 3 个，再把其中一个展开成共鸣搞笑型脚本。

提供参考视频或可访问链接、产品、目标受众、时长、平台、希望观众采取的行动和真实证据即可。只有文字稿时，会明确限制为文案结构分析。

默认偏好：陈述句标题、客户收益先行、自然英文、适量幽默，可通过提示覆盖。
